# Portfólio — Thays Nunes

Portfólio pessoal criado para apresentar conhecimentos e projetos de Front-end.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Como abrir
Abra o arquivo `index.html` no navegador.

Se estiver usando VS Code, você também pode abrir a pasta e usar uma extensão como Live Server/Live Preview.

## Antes de publicar
No arquivo `index.html`, procure por:

- `SEUEMAIL@EXEMPLO.COM`
- `SEU-USUARIO`

Substitua pelos seus dados reais.

## Projetos
Os projetos 2 e 3 estão identificados como projetos futuros. Não apresente como concluído algo que ainda não foi feito.

Quando um projeto estiver publicado, substitua o botão correspondente por um link para a página online e, se quiser, outro link para o repositório no GitHub.

## Arquivos
- `index.html` — estrutura do portfólio
- `style.css` — aparência e responsividade
- `script.js` — interação dos botões dos projetos
